Carpeta reservada para el futuro compilado de Android (.apk).

La versión móvil de Mayorix para Mayor Disluda se construirá sobre la misma
capa de datos y los componentes de la app de escritorio. Incluirá el acceso
del vendedor y la consulta de su cartera, pedidos y comisiones.

Referencia de compilación cuando el proyecto se prepare para Android:

    flet build apk

El artefacto se moverá o copiará a esta carpeta.
